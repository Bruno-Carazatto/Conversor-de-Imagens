# ⚡ QuickConvert — Conversor de Imagens no Navegador

> Conversor de imagens moderno, rápido e 100% client-side  
> Desenvolvido com foco em performance, UX e boas práticas de Front-End

---

## 🚀 Sobre o projeto

O **QuickConvert** é um conversor de imagens que funciona **inteiramente no navegador**, sem upload para servidor.

O objetivo deste projeto é mostrar, de forma prática, como um **Front-End Júnior** pode criar uma aplicação real, funcional e com ótima experiência do usuário utilizando apenas tecnologias básicas da Web.

---

## ✨ Funcionalidades

- ✅ Conversão de imagens **PNG / JPG / WEBP**
- ✅ Conversão **em lote (múltiplas imagens)**
- ✅ Controle de **qualidade (JPG / WEBP)**
- ✅ Redimensionamento opcional (largura / altura)
- ✅ Manter proporção automaticamente
- ✅ Fundo configurável para imagens com transparência
- ✅ Interface moderna com **Tema Claro / Escuro**
- ✅ Mensagens automáticas com UX refinada
- ✅ 100% client-side (nenhum arquivo é enviado para servidor)

---

## 🔒 Privacidade

> **Privacidade em primeiro lugar**

- Nenhuma imagem é enviada para servidor
- Todo o processamento acontece localmente
- Ideal para uso pessoal ou profissional

---

## 🧠 Por que este projeto é interessante?

Este projeto demonstra na prática:

- Manipulação de arquivos no navegador
- Uso da API de Canvas para conversão de imagens
- Controle de estado no Front-End
- Boas práticas de UX/UI
- Responsividade real (desktop → mobile)
- Organização de código (HTML / CSS / JS)
- Resolução de bugs reais de layout e renderização

Tudo isso **sem frameworks pesados**.

---

## 🛠️ Tecnologias utilizadas

- **HTML5**

- **Bootstrap 5**

- **File API**
